# ORxai v6 — خطوات الترقية

## 1) قاعدة البيانات (Supabase → SQL Editor) — بالترتيب
1. `supabase/migrations/018_plans_active_service.sql`  (الخطة + الخدمة النشطة للبوت)
2. `supabase/migrations/019_publish_notifications_announcements.sql`  (إيقاف النشر، إشعارات الطلبات، الإعلانات)

بدونهما يعمل النظام بالقيم الافتراضية (الجميع على الخطة المجانية، كل الخدمات منشورة، الإشعارات مفعّلة)، لكن لا تعمل
الإعلانات ولا تغيير الخطة ولا إيقاف النشر.

## 2) نشر الـ Worker ثم الواجهة
```
pnpm typecheck && pnpm build
```

## 3) ما الجديد
* الخطة المجانية: موقع منشور واحد + خدمة واحدة منشورة من كل نوع. إيقاف النشر يحرّر الخانة.
* الأدمن → المستخدمون: اختيار الخطة (مجانية / مدفوعة بلا حدود) لكل مستخدم.
* الأدمن → الإعلانات: بطاقات (نص / صورة / رابط / كلها) بمعاينة حية وجدولة وفئة مستهدفة وإحصاءات.
* البوت: ملخص، إيقاف/نشر الخدمة، إشعار فوري بالطلبات مع أزرار (تأكيد/منجز/إلغاء)، إنشاء خدمة جديدة.

## 4) تنبيه مهم عن إشعارات الطلبات
واتساب يسمح برسالة حرة للمستخدم فقط خلال 24 ساعة من آخر رسالة أرسلها هو للبوت. خارج ذلك ترفضها Meta
(الطلب نفسه يُحفظ ويظهر في اللوحة والبوت). للإشعار الدائم يلزم قالب رسالة معتمد من Meta.
